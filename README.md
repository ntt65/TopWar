# 러너 슈터 프로젝트 (가제)

지휘관이 병사 무리를 이끌고 전진하며, 총으로 보급 캡슐을 부숴 병력과 무기를 늘리고 적 무리와 보스를 돌파하는 **3D 러너 슈터 + 군단 성장** 모바일 게임 프로젝트입니다.

> 정식 게임명은 미정. 장르 메카닉은 참고하되, 특정 게임의 이름·캐릭터·아트·스테이지 구성은 따라 하지 않는다.

---

## 1. 게임 개요

* **장르:** 3D 러너 슈터 + 군단(Crowd) 성장
* **플랫폼:** Mobile (Android / iOS)
* **화면:** 세로(Portrait). 지휘관 뒤쪽 위에서 앞을 내려다보며 따라가는 카메라
* **좌표:** 칸(그리드) 없음. 모든 오브젝트는 **연속 좌표 (x, z)** 를 가진다. z = 전진 방향, x = 좌우
* **핵심 재미:**
  1. 좌우로 움직여 어떤 캡슐·게이트를 노릴지 고르는 선택
  2. 병사가 늘어나고 무기가 강해지며 화면이 탄막으로 채워지는 성장감
  3. 병종 상성(육군·공군·해군)을 맞춰 적 무리와 보스를 돌파하는 쾌감

---

## 2. 핵심 게임 루프

```text
[스테이지]
  지휘관 자동 전진 + 좌우 이동 + 자동 사격
        │
        ├─ 보급 캡슐 사격 → 게이지 0 → 병사(ARMY/AIR/NAVY)·무기·레벨업 획득
        ├─ 게이트 통과 → +N / xN / MERGE
        ├─ 적 무리와 교전 → 닿으면 병사·무기 손실
        ▼
  보스전 → 승리: 보석 획득 / 패배: 진행 거리만큼 보석

[스테이지 사이: 로비]
  보석으로 영구 강화 (병종 공격력, 시작 병력, 시작 무기)
```

## 3. 시스템 명세

### ① 맵과 좌표

* 스테이지는 앞으로 뻗은 직선 도로(다리). 폭 `-W ~ +W` 안에서만 움직인다.
* 오브젝트(캡슐, 게이트, 적, 보스)는 **전진 거리(z)** 와 **x 위치** 로 배치한다. 스테이지 데이터 = 거리별 배치 목록.
* 도로 한쪽에 보급 캡슐이 줄지어 있는 구간, 가운데로 적이 몰려오는 구간처럼 **구역은 기획상 나누되 판정은 모두 좌표와 반경**으로 한다.

### ② 지휘관 (Player)

* 키 입력·드래그를 받는 단 하나의 캐릭터. 병사보다 크고 다른 색으로 구분한다.
* 자동 전진, 좌우 이동(상대 드래그 / `←→` `A D`), 자동 사격.
* 무기 단계(아래 ⑤)에 따라 연사 속도와 피해가 오른다.
* 병사와 무기를 모두 잃은 상태에서 적에 닿으면 패배.

### ③ 병사 (Soldier)

* 지휘관 주변에서 따라다니며 각자 앞으로 사격한다.
* 병사마다 **병종(ARMY / AIR / NAVY)** 과 **레벨(1~10)** 을 가진다. 한 무리 안에 병종이 섞일 수 있다.
* 대형: 지휘관을 중심으로 둥글게 모이고, 서로 최소 거리를 유지한다(분리). 수가 늘면 대형이 넓어진다. 도로 밖으로는 나가지 않는다.
* 공격력 = 레벨 공격력(Lv마다 2배) × 영구 강화 배율 × 상성.

### ④ 사격과 충돌

* 총알은 실제로 앞으로 날아가는 투사체. **처음 닿은 대상** (적, 캡슐, 보스)에 피해를 준다.
* 적은 지휘관 쪽으로 다가온다. 적이 병사나 지휘관에 닿으면 그 적은 사라지고, **적의 남은 피해량만큼 병사를 잃는다** (낮은 레벨부터).
* 병사가 없으면 무기 단계가 내려가고, 무기도 기본 단계면 패배.

### ⑤ 보급 캡슐과 무기

* **보급 캡슐:** 숫자(게이지)가 적힌 통. 총알로 게이지를 0으로 만들면 열리고 보상이 나와 지휘관 주변에 합류한다. 부수지 못하고 지나치면 사라진다.
  * 병사: `ARMY +5`, `AIR +3`, `NAVY +4` 처럼 병종과 수
  * 무기: 지휘관 무기 단계 +1 (예: 권총 → 소총 → 기관총 …)
  * 레벨업: 무리 전체 또는 일부 병사 레벨 +1
* **대형 캡슐:** 게이지가 매우 큰 캡슐. 부수면 고레벨 정예 병사가 합류한다.
* 캡슐 모양은 처음에는 박스·판넬 같은 기본 도형으로 만든다.

### ⑥ 게이트

* 일정 폭의 판넬. 지휘관이 통과하면 적용된다. 두 갈래로 놓아 선택하게 할 수도, 하나만 놓을 수도 있다.
* `+N` (병사 추가), `xN` (병사 수 배수), `MERGE` (같은 병종·레벨 2명 → 다음 레벨 1명), `-N` (함정)

### ⑦ 적과 보스

* **일반 적:** 개별 위치·체력·병종을 가진 병사. 무리로 몰려온다. 피격 시 피해 숫자 표시.
* **정예 적:** 체격이 크고 체력 바·남은 체력 숫자 표시.
* **보스:** 스테이지 끝. 지휘관이 멈춰 제한 시간 동안 싸운다. 시간 안에 쓰러뜨리면 승리.
* 상성: 육군 > 공군 > 해군 > 육군. 유리 +25%, 불리 -15%.

### ⑧ 성장과 재화

| 재화 | 획득 | 사용 |
| --- | --- | --- |
| 보석 | 스테이지 클리어(승리 보너스) + 진행 거리 | 로비 영구 강화 |

* **영구 강화:** 병종별 공격력, 시작 병사 수, 시작 무기 단계
* 진행 상황은 기기에 저장한다.

## 4. 기술 스택

* **Engine:** Unity 6.3 LTS (6000.3.29f1), 3D, URP
* **Language:** C#
* **Input:** Input System (상대 드래그 + 키보드)
* **Test:** Unity Test Framework (EditMode: 규칙 로직)
* **CI:** GitHub Actions + GameCI
* **아트:** 처음부터 CC0 로우폴리 애니메이션 캐릭터(Quaternius)와 파티클(Kenney). 기본 도형 캐릭터는 쓰지 않는다
* **대용량 파일:** Git LFS

### 게임 로직 구조 원칙

* 이동·사격·충돌·캡슐·게이트·보상 같은 **게임 규칙은 순수 C#(`Core`)** 으로 작성하고 EditMode 테스트로 검증한다. 시뮬레이션은 고정된 `Tick(deltaTime)`으로 진행한다.
* MonoBehaviour(`Game`)는 화면 표시, 입력, 연출만 담당한다.
